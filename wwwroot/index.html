UNDER THE HOOD

Built beyond the chat window.

The project focuses on backend integration, application security, request management and reliable communication with an external AI service.

01

AI API Integration

Connected Maincode's Matilda AI API to an ASP.NET Core backend using HttpClient.

02

Secure Configuration

Configured API credentials using ASP.NET Core User Secrets to keep sensitive information server-side.

03

Conversation Management

Implemented conversation history to maintain context across successive messages.

04

Input Validation

Added message validation, role restrictions and request size limits.

05

Rate Limiting

Implemented request rate limiting to help protect the application against excessive requests.

06

Error Handling

Added handling for API failures, HTTP errors, invalid responses and request timeouts.
